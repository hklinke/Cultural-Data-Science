# Cultural-Data-Science
This repository contains the code and materials associated with my book "[Cultural Data Science]([https://www.waterstones.com/book/cultural-data-science/harald-klinke//9783031881299](https://link.springer.com/book/10.1007/978-3-031-88130-5))". It provides examples and scripts to support the application of data science methods in cultural research.
